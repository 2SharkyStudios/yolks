# Yolks
[![Last Commit](https://img.shields.io/github/last-commit/2SharkyStudios/yolks?label=last%20commit)](https://github.com/2SharkyStudios/yolks/commits) [![Stars](https://img.shields.io/github/stars/2SharkyStudios/yolks)](https://github.com/2SharkyStudios/yolks/stargazers)



A curated collection of core images that can be used with Pterodactyl's Egg system. Each image is rebuilt periodically to ensure dependencies are always up-to-date. Its each monday at 12:00 PM UTC

All of these images are available for `linux/amd64` and `linux/arm64` versions, unless otherwise specified, to use
these images on an arm system, no modification to them or the tag is needed, they should just work.
